# Privacy Policy

**Effective date: August 18, 2026**

## 1. Overview

Oura Excel is a personal, non-commercial application created for the purpose of retrieving the application owner's own Oura data and displaying it in a local Microsoft Excel workbook.

The application is not offered as a public service and is not intended for use by other users.

## 2. Data Accessed

Oura Excel may access the following data through the Oura API:

* Sleep Score
* Total sleep duration
* Heart Rate Variability (HRV)
* Resting heart rate
* Readiness Score
* Date associated with the measurements

Only data necessary for the application's personal analysis purpose is accessed.

## 3. Purpose of Processing

The data is used solely for personal health and wellness tracking, analysis, visualization, and historical comparison in Microsoft Excel.

The data is not used for advertising, marketing, profiling, automated decision-making, or commercial purposes.

## 4. Data Storage

Oura data retrieved by the application is stored locally in an Excel workbook controlled by the application owner.

The application does not operate its own external database or cloud storage service for Oura data.

Data is retained only for as long as reasonably necessary for the personal analysis purpose for which it was retrieved.

## 5. Data Sharing

Oura Excel does not sell, rent, disclose, or intentionally share Oura user data with third parties.

Data may only be processed by services technically necessary to provide the Oura API or Microsoft Excel functionality.

## 6. Security

Reasonable measures are used to protect API credentials and locally stored data.

Access tokens and other authentication credentials are intended to remain private and must not be publicly disclosed.

## 7. Data Deletion

The application owner may delete the locally stored Excel data at any time.

If use of the Oura API is discontinued, stored Oura data will be deleted when required by applicable Oura API terms or applicable law.

## 8. Oura

Oura Excel is an independent personal project and is not affiliated with, endorsed by, or operated by Oura Health.

Oura data is accessed through the official Oura API subject to Oura's applicable API terms and policies.

## 9. Changes to This Policy

This Privacy Policy may be updated if the functionality or data processing practices of Oura Excel change.

## 10. Contact

Questions regarding this Privacy Policy may be directed to the owner of the GitHub repository hosting this policy.
